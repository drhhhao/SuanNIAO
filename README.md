# 蒜鸟（SuanNIAO）

**把安卓手机变成电脑的触控板、快捷键面板和语音输入。**

手机和电脑用蓝牙或同一个 Wi-Fi 连在一起，不用数据线。靠在椅子上、躺在沙发上，或者电脑接在电视、投影上的时候，拿着手机就能动鼠标、按快捷键、说话打字。

特别适合一边和 AI 编程助手聊天一边写代码（vibe coding）：说一句话，字就打进电脑上的对话框；常用的「回车」「换行」「撤销」「中断」做成手机上的大按键，一按就行。

## 功能

- **触控板**：单指移动鼠标、轻点单击，双指滚动、右键，三指中键，轻点后按住拖动。指针走得顺滑，不一顿一跳。
- **快捷键面板**：手机上的按键想放几个放几个，每个键能做一串动作：
  - 按键和组合键（Ctrl+C、Shift+Enter……）、鼠标按键和滚轮、移动光标、输入一段文字、等一会儿、打开程序、打开网页、播放 / 暂停这类媒体键。
  - 同一个键单击、双击、长按可以做三件不同的事；按住不放可以连发（比如一直删），也可以像实体键盘一样按住不放（比如按住 Shift）。
  - 按键可以分几页放；可以存几套「方案」，按一个键就切换。
  - 内置一键预设：常用、写代码和终端、导航和鼠标、媒体。
- **语音输入**：按住手机上的语音键说话，说的话变成带标点的文字，直接打在电脑上光标所在的地方。
  - 识别在手机上完成，**录音不上传、不用联网**；中英文混着说也认得。
  - 可以边说边往电脑上打字，也可以说完一句再整句发；说得久可以上滑锁定。
  - 断线时说的话先存在手机上，连上以后问你要不要发。
- **剪贴板同步**：手机上复制的文字，回到蒜鸟以后电脑上就能粘贴；电脑上复制的文字、图片，手机上直接就能粘贴。密码管理器复制的密码不会同步。
- **手机文件发到电脑**：在相册、微信、文件管理里把照片、文档「分享 → 蒜鸟」，就发到电脑「下载」文件夹里的「蒜鸟」。发一张图片时它还会直接放进电脑剪贴板，回到电脑上的 AI 对话框 Ctrl+V 就能粘进去；别的文件 Ctrl+V 能粘进文件夹、聊天软件。连着局域网时很快（实测每秒 3～4 MB），只连着蓝牙时适合截图、小文档。
- **在电脑上排布局、配按键**：电脑上的蒜鸟能拖动摆放手机上的每个按键、改大小、配动作，改完手机马上跟着变；也能在手机上直接拖着调。改错了能撤销。
- **自动更新**：发了新版本，电脑和手机上的蒜鸟都会提示，点「立即更新」就行，设置都会留着。

## 需要什么

- **电脑**：Windows 10 或 11。用蓝牙连要电脑带蓝牙（笔记本一般都有；台式机可以插一个蓝牙适配器）；用局域网连不用蓝牙，和手机连同一个网络就行。
- **手机**：安卓 9 及以上的 64 位手机（近几年的手机基本都是）。在小米 13 上开发和测试。

## 下载安装

到 [Releases 发布页](https://github.com/drhhhao/SuanNIAO/releases/latest) 下载最新版，电脑和手机各装一个（页面上的「Source code」是源代码，不用下）：

1. **电脑**：下载「电脑版安装包」（`SuanNIAO-PC-版本-Setup.exe`），双击安装。
   - 不用管理员权限，装好后开始菜单里有「蒜鸟」，也可以在桌面放一个。
   - 想装到别的盘：安装界面「装在」那一行点「更改」选文件夹。已经装过的，重新运行安装包换个文件夹，就会整个搬过去，设置都留着。
   - 如果 Windows 提示「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」（安装包没有做代码签名，所以会这样提示）。
2. **手机**：下载「手机版安装包」（`SuanNIAO-Android-版本.apk`），在手机上打开安装。
   - 手机会问是否允许从这个来源安装应用，允许就行。
   - 安装包里已经带着语音识别的模型（所以有一百多 MB），装好就能用语音输入，不用另外下载。

**手机该下哪个**（发布页上手机版有两个文件）：

| 你的情况 | 下哪个 | 大小 |
|---|---|---|
| 第一次装蒜鸟，或者卸载过要重装 | 完整安装包 `SuanNIAO-Android-版本.apk` | 一百六十 MB 左右，带语音模型 |
| 手机上已经装着蒜鸟 | 不用去网页下：蒜鸟提示有新版本时点「立即更新」，它自动只下更新包 `SuanNIAO-Android-版本-update.apk` | 三十 MB 左右，语音模型留在手机上不用再下 |

- 更新包不带语音模型，是给 App 里自动更新用的，**第一次装别下它**（装上以后本地语音识别用不了）。
- 换了语音模型的版本，更新说明里会写明；那一次蒜鸟会自动下完整安装包，不用另外操作。

## 使用教程

两边第一次打开时都有一份带动画的使用教程，跟着走一遍就会用。以后想再看：手机上点右上角「⋯」→「使用教程」，电脑上点首页右上角的「使用教程」。

### 第一次连接（只要做一次）

先在电脑上打开蒜鸟：屏幕右下角的托盘里会出现一只小鸟（没看到就点一下托盘的「^」），说明它在等手机来连。电脑上的窗口关掉也没关系，托盘里有小鸟就行。

然后选一种连接方式（两边的教程里也是先选这个）。两种都能用，先选一种连上，另一种以后也能加；拿不准就选蓝牙。

| | 蓝牙 | 局域网 |
|---|---|---|
| 什么时候用 | 不用网络，在哪都能连 | 手机和电脑连着同一个 Wi-Fi（或同一个校园网）时 |
| 好处 | 稳定 | 延迟更低、触控板更跟手；传文件快得多 |
| 要做什么 | 扫码配对一次（或者在系统蓝牙里配对、选电脑） | 扫一次电脑上的二维码 |

**用蓝牙连（扫码配对，最省事）：**

1. 电脑上打开蒜鸟：首页「连接手机」里点「扫码配对」，或者「设置 → 扫码连接 → 显示二维码」（同一个二维码）。
2. 手机上打开蒜鸟，点右上角「⋯」→「选择电脑」→「扫码配对新电脑」，对准电脑上的二维码。
3. 手机会弹出系统的「配对」确认，点一下就好；电脑这边蒜鸟自动同意，不用点。配好就自动选上这台电脑、连上了。

**用蓝牙连（在系统蓝牙里配对）：**

1. **让手机和电脑蓝牙配对。**
   - 手机：打开蓝牙设置页，停在那一页别退出，电脑才找得到这部手机。
   - 电脑：打开「设置 → 蓝牙和其他设备 → 添加设备 → 蓝牙」，选你的手机。
   - 两边会弹出同一串数字，核对一样后两边都点确认。
2. **在手机上打开蒜鸟，选你的电脑。** 列表里是和这部手机配对过的设备，点你的电脑。

**用局域网连：**

1. 电脑上打开蒜鸟，点「设置」，在「扫码连接」里点「显示二维码」。（第一次可能弹出 Windows 防火墙的提示，选「允许」。）
2. 手机上打开蒜鸟，在教程的扫码那页点「扫码」，或者点右上角「⋯」→「扫码连接电脑」，对准电脑上的二维码。第一次会问能不能用相机：只在扫码时打开，不拍照、不存图；不想给的话，可以把二维码截图，从相册里选。（也可以用手机自带的相机、「扫一扫」扫，扫出来的链接选蒜鸟打开。）
3. 手机提示「已绑定」就好了。以后只要在同一个网络里，打开蒜鸟就自动连上。
4. **小米等手机要放开后台限制**，不然手机息屏、切到别的 App 一会儿以后，系统会冻结蒜鸟、掐断局域网（蓝牙不受影响）。扫好码以后蒜鸟会带你去改：小米是在「省电策略」里选「无限制」。以后也能在「⋯ → 后台保持局域网」里改。

连好以后，只要两边都开着蒜鸟就会自动连上。电脑上的蒜鸟首页会显示「已连接」、用的是蓝牙还是局域网，还有手机的名字、电量。

两种可以同时连着：都连着时走局域网，局域网断了（比如手机离开了 Wi-Fi）自动接着用蓝牙。手机「⋯ → 扫码连接电脑」扫一次能两种都加上：同一个网络里绑上局域网，蓝牙开着的话顺便配对。只想加一种：「⋯ → 选择电脑 → 扫码配对新电脑」只配蓝牙，「扫码走局域网」只绑局域网。局域网的连接是加密的，只有扫过码的手机连得上。不想用了：电脑「设置 → 扫码连接」里点「解除绑定」，或者手机「⋯ → 解除局域网绑定」。

> 连不上的话，电脑上的蒜鸟首页会逐项检查：后台在不在运行；蓝牙的看电脑蓝牙开没开、和手机配对过没有；局域网的看扫码绑定过没有。哪一项不对就写着怎么办。

### 触控板

和笔记本电脑的触控板一样用：

| 手势 | 作用 |
|---|---|
| 单指滑动 | 移动鼠标 |
| 单指轻点 | 左键单击 |
| 双指滑动 | 滚动（松手还会顺着滑一段） |
| 双指轻点 | 右键 |
| 三指轻点 | 中键 |
| 轻点一下，马上按住拖 | 按住左键拖动（选中文字、拖窗口） |

速度、加速、滚动快慢、自然滚动方向，都能在电脑上的蒜鸟「设置」里调。

### 按键

- 点一下按键，电脑就做这个键配好的事，比如点「复制」，电脑就按下 Ctrl + C。
- 键角写着「长按」「双击」的，长按、双击还能做另一件事。
- 「删除」这类键按住不放会一直删。
- 刚装好时手机上只有语音和触控板。想加按键，在电脑上的蒜鸟里点「**添加按键**」，加好会自动出现在手机上。

### 语音输入

- 按住语音键说话，松手结束。说的话会变成文字，打在电脑上光标所在的地方。
- 要说很久，按住往**上滑**锁定，之后可以松手，说完**点一下**结束。
- 右上角「⋯」里能选：
  - **本地识别**（默认，不联网）：「快」出字快，「更准」错字少一点；
  - **系统引擎**：用手机自带的语音识别，要联网、没有标点；
  - **边说边打字**：开着时说一段打一段；关掉后停顿一下再整句发。

### 手机上的「⋯」菜单

右上角的「⋯」里有：调整布局（直接在手机上拖动按键、改大小）、暂停按键、发文件到电脑、语音识别的选项、选择电脑（换一台用蓝牙连的电脑）、扫码连接电脑（蓝牙配对、局域网绑定）、使用教程、手势说明、检查更新、关于。

### 在电脑上编辑布局和按键

电脑上的蒜鸟窗口（点托盘里的小鸟打开）左边有几页：

- **首页**：连接状态、今天按了多少次键、说了多少字、最近做过的动作。
- **布局**：手机上按键的摆放。拖动按键换位置，拖边和角改大小，可以加几页、改网格。
- **映射**：每个按键单击、双击、长按各做什么，按住时连发还是像实体键一样按住。动作能复制粘贴、存起来以后再用，组合键可以直接「录制」。顶上能新建、切换方案。
- **总览**：所有按键配了什么，一张表看完。
- **设置**：触控板、语音输入、按键判定（双击、长按算多快）、剪贴板同步、接收文件（存到哪、收到后放不放进剪贴板）、扫码连接（蓝牙配对、局域网绑定）、开机自启；能导出、导入备份。
- **关于**：版本号、检查更新。

所有改动自动保存，手机马上跟着变；改错了按 Ctrl+Z 撤销。顶栏的「按键映射」开关能临时让手机上的按键全部不起作用（触控板和语音照常）。

关掉这个窗口不影响使用：托盘里的后台照样工作，手机照样连着。

### 剪贴板同步

默认开着，在电脑上的蒜鸟「设置 → 剪贴板」里能关。

- **手机 → 电脑**：在手机上复制一段文字，切回蒜鸟，电脑的剪贴板就是这段了，按蒜鸟上的粘贴键（或电脑上 Ctrl+V）就能粘上。
- **电脑 → 手机**：在电脑上复制文字或截图、复制图片，手机的剪贴板马上就是它，在微信、QQ 这类地方直接粘贴。图片走蓝牙要传几秒，蒜鸟顶上会提示「已放进手机剪贴板」，这之后再粘贴。

### 手机文件发到电脑

- **怎么发**：在相册、微信、文件管理这类地方选好文件（可以多选），点「分享」，选「蒜鸟」。或者在蒜鸟右上角「⋯ → 发文件到电脑」里选。只分享一段文字的话，它会放进电脑剪贴板。
- **存在哪**：电脑「下载」文件夹里的「蒜鸟」，重名的会自动加「 (1)」。电脑上蒜鸟「设置 → 接收文件」里能换文件夹、一键打开。
- **收到以后**：电脑右下角提示一声，点提示会打开文件夹并选中它。默认还会放进电脑剪贴板：只发了一张图片就是图片本身（直接粘进 AI 对话框、聊天框），别的是文件（粘进文件夹、微信电脑版）。不想要可以在「设置 → 接收文件」里关掉。
- **快慢**：连着局域网时发原文件，一张照片一秒左右，一段几十 MB 的视频十几秒。有的手机（比如小米）在蒜鸟开在前台时会把它往外发的速度压到每秒 0.2 MB 左右，所以大文件最好在相册、文件管理里「分享 → 蒜鸟」发，蒜鸟不用开着。发得明显慢时，蒜鸟会按当时的情况告诉你怎么快起来（比如在手机设置里放开对蒜鸟的后台限制）。只连着蓝牙时慢得多（每秒约 55 KB）：超过 1 MB 的照片会先压缩再发，超过 3 MB 的其他文件不发，会提示你连上局域网再发。
- 发的时候手机通知栏和蒜鸟顶上会显示进度，通知上能「取消发送」。发文件时触控板、按键照常能用。

### 更新

- 发了新版本，电脑托盘会弹一条提示，打开蒜鸟会弹出更新窗口，写着新版本号和这次更新了什么。点「立即更新」，蒜鸟会自己下载、装好、重新打开，设置都会留着。不想更新可以点「以后再说」或「跳过这个版本」。
- 手机上的蒜鸟也会提示，点「立即更新」下载后交给系统安装（第一次会问是否允许安装应用）。只下三十 MB 左右的更新包：语音模型第一次装时就在手机上了，更新前蒜鸟会把它留在手机存储里，新版接着用，不用每次再下一百多 MB。
- 新版本会先从国内的 Gitee 下载（比 GitHub 快得多），那边不行再从 GitHub 下。不管从哪下，蒜鸟都会先核对是不是原版的安装包，对不上就不装。
- 随时手动检查：电脑上「关于 → 检查更新」，手机上「⋯ → 检查更新」。

### 卸载

- 电脑：「设置 → 应用 → 已安装的应用」里找到「蒜鸟」卸载。会先关掉开着的蒜鸟，可以选要不要顺带删掉设置（不删的话以后重新安装还能接着用）。
- 手机：和别的 App 一样卸载。

## 常见问题

**电脑开机就能用吗？** 电脑上的蒜鸟第一次打开时会问要不要「开机自动启动后台」，之后在「设置」里也能改。开着的话，开机后托盘里就有小鸟，手机打开蒜鸟就能连上。

**手机锁屏、切到别的 App 还连着吗？** 连着。蒜鸟在通知栏有一条常驻通知，那里能暂停按键或断开。按返回键只是把蒜鸟退到后台，不会断开。

**会联网吗？** 按键、语音识别都不联网；用局域网连时，手机和电脑只在你自己的网络里直接连，不经过外面的服务器。只有「检查更新」会连 GitHub 和它在国内的镜像 Gitee 看有没有新版本；不想要的话，两边都能关掉自动检查更新。选「系统引擎」做语音识别时，是手机系统自带的识别在联网。

**一台电脑能连几部手机？** 一次连一部。一部正连着时，另一部扫码绑定过的手机连不上来，要等这部断开；没扫码绑定过、只用蓝牙的手机连上来，会顶掉原来那部。

**扫码以后连不上局域网？** 手机和电脑要连着同一个网络（或者能互相访问的网络，比如同一个校园网）。看看电脑的 Windows 防火墙有没有拦住蒜鸟；有的 Wi-Fi（访客网络、一些公共 Wi-Fi）开了「设备隔离」，设备之间连不通，这时用蓝牙。

**局域网用着用着断了？** 多半是手机在后台把蒜鸟冻结了：到手机「设置 → 应用 → 蒜鸟」里放开后台限制（小米：「省电策略」选「无限制」），或者点蒜鸟「⋯ → 后台保持局域网」。回到蒜鸟时它会马上重连。

电脑端是 Rust + [Slint](https://slint.dev)，手机端是 Kotlin；本地语音识别用的是 [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) 和 [X-ASR](https://github.com/Gilgamesh-J/X-ASR) 模型。各自的许可证在手机上「⋯ → 关于 → 开源许可」里能看到。
